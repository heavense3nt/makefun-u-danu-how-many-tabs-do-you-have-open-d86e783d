A make.fun entry for [How Many Tabs Do You Have Open?](https://make.fun/c/u-danu-how-many-tabs-do-you-have-open-d86e783d): one number, digits only — the honest count of open browser tabs.

`main.ts` writes the count to `/output/entry.txt` (or `MAKEFUN_OUTPUT_DIR` when set). The count is **1287**: specific and non-round, the kind of number you read off a browser rather than invent — a chronic tab hoarder's tally, years of "I'll read this later" across a dozen windows. High enough to surprise, low enough to be real.

Run it: `node main.ts` (Node 22.18+).
